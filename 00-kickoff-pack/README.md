# Kickoff Pack

Ce dossier référence les livrables de cadrage principaux pour le projet.

## Documents inclus
- `01-project-brief.md` — brief technique du projet
- `02-product-scope.md` — périmètre produit et backlog MoSCoW
- `03-domain-model.md` — modèle métier, RBAC, règles et cas d'erreur
- `04-database.md` — schéma de base de données et dictionnaire de données
- `05-architecture.md` — architecture, responsabilités, sécurité et observabilité
- `06-adr/` — ADR structurants pour les choix technologiques
- `07-tech-debt-register.md` — registre de dette technique et risques identifiés
- `08-definition-of-done.md` — checklist finale de cadrage

## Utilisation
1. Relire chaque document pour s'assurer que le cadrage couvre bien le besoin métier et technique.
2. Utiliser `02-product-scope.md` pour lancer le backlog du Sprint 1.
3. Vérifier `07-tech-debt-register.md` à la fin de chaque sprint.
4. Cocher la checklist dans `08-definition-of-done.md` avant de démarrer le développement.
